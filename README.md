Data Analytics Internship – Task 3 (Sales Dashboard)

This repository contains my submission for Task 3 of the Data Analytics Internship.

Dataset - Sample Superstore Dataset

Objective - The objective was to create a basic interactive sales dashboard to present key sales performance metrics and allow users to explore product and regional performance.

Tools Used
1. Power BI Desktop
2. Sample Superstore Dataset
3. GitHub

Dashboard Components
1. Total Sales KPI
2. Total Profit KPI
3. Total Quantity KPI
4. Total Sales by Category chart
5. Total Sales by Region chart
6. Total Sales by Sub-Category chart
7. Region slicer for interactive filtering

Analysis Performed
1. Reviewed the cleaned Sample Superstore dataset
2. Created KPI cards for Sales, Profit, and Quantity
3. Compared total Sales across product categories
4. Compared total Sales across regions
5. Analyzed Sales across product sub-categories
6. Added a Region slicer for interactive analysis
7. Tested the slicer to ensure that the dashboard visuals and KPIs update based on the selected region

Dashboard Interactivity - The Region slicer allows users to select a specific region. When a region is selected, the KPI cards and charts automatically update to display the corresponding regional performance. Clearing the selection returns the dashboard to the overall dataset view.

Dataset Note - The cleaned Sample Superstore dataset does not contain a Date or Month field. Therefore, monthly analysis and a month filter were not included in the dashboard.

Files
1. Task 3.pbix - Interactive Power BI dashboard
2. Sales Dashboard Note.pdf - One-page note explaining how to read the dashboard
3. README.md - Summary of the dashboard project

Conclusion - The Sample Superstore dataset was transformed into an interactive Power BI dashboard containing key performance indicators, product-level analysis, regional analysis, and an interactive Region slicer. The dashboard provides a simple visual summary that can help stakeholders understand sales performance.
